# README maintenance notes

The main README is a project specification and implementation overview. Keep these points accurate when the application changes:

- Remove template placeholders before presenting the repository as production-ready.
- Keep the documented stack aligned with the actual `Frontend`, `Backend`, and `Admin` directories.
- Document the real local startup commands from the current package manifests instead of generic MERN examples.
- Never put credentials, connection strings, or other secrets in documentation.
- When a feature described in the requirements is not implemented yet, label it as planned rather than completed.

This checklist is intentionally separate from the historical requirements text so contributors can update the README without rewriting the original project documentation in one large change.
